## 1. Tujuan

Menindaklanjuti feedback pemakaian nyata menu admin setelah Fase 1-4 tuntas. Enam permintaan, dikelompokkan jadi 3 area:

- **Tampilan Halaman Index** (menu "Tampilan Halaman Index", Fase 4): preset warna aksen belum interaktif (klik warna lain tidak memberi umpan balik visual) + tidak ada input warna custom bebas; pilihan gaya animasi/efek reveal-on-scroll cuma 1 (on/off), perlu lebih banyak gaya dengan hanya 1 yang aktif sekaligus.
- **Kebersihan menu**: hapus menu "Playground" beserta seluruh sisa referensinya (section publiknya sendiri sudah dihapus total sejak Iterasi 19, menu admin ini sudah jadi placeholder mati sejak saat itu).
- **Blog & Projects (konten)**: editor blog perlu rich text editor modern (bukan textarea polos) supaya body artikel bisa memuat format kaya (bold/italic/list/link/code/quote); form admin Projects perlu tata letak yang mencerminkan halaman publik `/projects/{key}` supaya admin lebih mudah membayangkan hasil akhirnya sebelum publish, ditambah kontrol hide/unhide per-blok konten dan galeri multi-gambar per project.

## 2. Cara kerja dokumen ini — sama seperti Fase 3 & 4

- `LOG-ITERASI.md` (file yang sama, dipakai bersama seluruh fase) dicatat setiap iterasi selesai. `ERD.md` diupdate setiap ada perubahan skema.
- **TIDAK ADA `git commit` otomatis** di seluruh Fase 5 — setiap perubahan dibiarkan uncommitted di working tree, user review & commit manual sendiri per iterasi (instruksi eksplisit user, konsisten dgn kebiasaan Fase 3-4).
- **Iterasi TIDAK dirantai otomatis** — tiap iterasi berhenti menunggu instruksi lanjut, supaya working tree tidak menumpuk perubahan dari beberapa iterasi tanpa checkpoint commit yang jelas.
- Nomor iterasi melanjutkan dari Fase 4 (berakhir di Iterasi 23) — Fase 5 mulai dari **Iterasi 24**.
